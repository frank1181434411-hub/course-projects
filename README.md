# Tank Battle

Tank Battle 是一个使用 C++17 和 SFML 3.1.0 开发的复古坦克大战课程设计项目。当前项目已经完成基础战斗、文本地图、地形碰撞、敌方 AI、随机道具、菜单/HUD、局域网双人合作、贴图和音效接入。

## 当前状态

- 已完成：程序启动、窗口创建、玩家移动和射击、敌方坦克、炮弹伤害、基地、血包、弹药强化包、地图加载、地形碰撞、砖墙破坏、坦克互撞、胜负判定、简单/普通/困难 AI、菜单、HUD、暂停、结算界面、局域网主机/加入、UDP 主机发现、主机权威快照同步、贴图和音效。
- 部分完成：在线游戏结束后的联机收尾、断线恢复、网络异常处理、完整自动化回归测试。
- 暂不实现：地图编辑器、敌人波次持续生成。
- 可选功能：强化学习 AI。

## 技术栈

- C++17
- SFML 3.1.0
- CMake
- Ninja
- MSYS2 UCRT64
- Visual Studio Code

## 基本操作

- 玩家移动：`W/A/S/D`
- 玩家射击：`Space`
- UI 选择和切换：方向键或 `W/A/S/D`
- UI 确认：右侧小键盘 `Enter`
- 暂停或返回：`Esc`

## 构建与运行

在 MSYS2 UCRT64 终端中执行：

```bash
cd /d/CPP/tank-battle
cmake --preset debug
cmake --build --preset debug
./build/debug/bin/TankBattle.exe
```
