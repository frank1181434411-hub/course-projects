# 实验一：网络设备认知与 IPv6 隧道设计

实验日期：2026-11-28。状态：**配置方案完成，Packet Tracer 实际搭建与验证待完成**。姓名、学号、班级未填；本报告为脱敏版。

## 实验目的

理解交换机与路由器的工作原理及基本配置；熟悉网络模拟器；理解 IPv4 到 IPv6 过渡中的 IPv6-over-IPv4 隧道技术。

## 实验原理

交换机在二层按 MAC 地址转发，路由器根据三层路由表选择路径。两个 IPv6 LAN 通过只配置 IPv4 的路由器互联链路通信时，可用手工配置的 IPv6-in-IPv4 隧道。入口将完整 IPv6 包封装在 IPv4 包内，外层 Protocol 为 41；出口去除外层 IPv4。两端仍需开启 IPv6 路由并配置对端 LAN 路由。此处是理论分析，尚无 Simulation 观测结果。

## 实验设计过程

已阅读指导书、PPT 和报告模板。以指导书图 1 为准：R1、R2 两台 2811，SW0、SW1 两台 2960，PC0、PC1 位于左侧，PC2、PC3 位于右侧。PPT 和附带样例仅为参考，不采用其简化设备数量。

设计 WAN 为 10.1.1.0/24，R1/R2 分别为 .1/.2；LAN 分别 2001:db8:1::/64 和 2001:db8:2::/64；Tunnel0 为 2001:db8:12::/64。PC1 地址 2001:db8:1::11，PC2 地址 2001:db8:2::12。FastEthernet0/0 用作 WAN，FastEthernet0/1 接本侧交换机。具体端口、四台 PC 地址和操作见 [SETUP.md](SETUP.md)。

已生成 [R1.cfg](router-config/R1.cfg)、[R2.cfg](router-config/R2.cfg)，包括接口启用、IPv6 单播路由、`tunnel source`、`tunnel destination`、`tunnel mode ipv6ip` 及对端 LAN 的静态路由。这些是待输入配置，尚未从设备导出 running-config。
